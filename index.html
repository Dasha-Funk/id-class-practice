ID Attribute

What does the ID attribute do?

The ID attribute is used to specify a unique id for an html element. The value of ID attribute is case sensitive. The Id attribute can only be used once per html document. The ID is used to point to a specific element that I wish to change in my CSS or javascript. The id attribute can be given any name that i wish. However i need to make sure that it is specific and easily understood. For example, if I wish to change the color of my main heading, I can use an id such mainheading, to let me know that i want that heading to be changed. That is the only time i can use that id name. IF i have other id attributes, i will have to use a different name for it.

CLASS Attribute

What does the Class attribute do?

The class attribute is used to point to a class name in CSS as well as javaScript. Unlike the id attribute, the class attribute can be repeated infinitely. One HTML element can have an infinite amount of classes. for example, if i wish to create a class of city for all the cities in my document, i can create that class in every line of code that has a city name. See example below.

Paris

Mexico City

San Antonio

Each class attribute can have more than one value. The value is the name i give to the class. We separate the values with a space in between. Example Below.

Paris

Mexico City

San Antonio

Every element that has the class and value of city will be affected by the changes in CSS.
