Block and Inline HTML Elements

What is Block Html Element?

Block Tags is a reserved block of space around an element's content area. The Block includes the padding, border and margin all within the content block. However, the p element for paragraph does not have a block tag. The block will expand its WIDTH to fill its parent container. The container is the space of the page. The content is what is within the element. This is a paragraph element, therefore it will not have a block tag to it. However, a heading element will. Below I will create a heading to show this. This can only be seen through the web inspector.

This is a heading that has a block tag to it. H2 is the element that contains the content.

All headings are elements that have block tags. This h4 heading is a block as well. All blocks will stack below the previous block. They also will expand their height naturally to fit the content.

However the height and width of a block cn be changed through a cascading style sheet. Also known as CSS. Not only can the height and width be changed, but the padding, margin and border can be changed as well through CSS.

What is Inline HTML Tag?

In Line tags are used to identify select content WITHIN a block element. Such as an em element that is placed in front of text to make it italic. Or the strong element to let the reader know it is important text. These elements do not start on a new line. They only take up as much width as necessary unlike the block element that takes all the width that is available on the page.

Examples of Inline Elements

  • a
  • b
  • em
  • strong
  • img
  • button
  • map

There are many more inline elements. Inline elements are greatly restrictive in the space and movement control then blocks. However there is a way to turn an inline into a block.
