Cascades and Indentations

What is Cascades?

Cascade is a series of indentations to represent the child/parent relationship throughout the code. It makes the code easy to read. It is presented in a clear way which makes your code more readable to others.

Element Relationships

In HTML there are element relationships that take place, that allows the code to be presented in a clean way. This relationship is also called 'housing' or nesting'. Where one element is 'nested' into another. There are 3 main Elements in this relationship. The Parent, Child and Sibling Element. The Parent element wraps the child. The Child element wraps the Sibling. How would this looks like? In my previous pages I created lists. Those are a great example of how this relationship works. The UL was the parent element and the LI was the child element. To make the List possible, i had to define a parent element, which was ul. Then the LI became the child element which housed the actual content of the list. Now this relationship only had a Parent and a child Element. What about the sibling? To have all 3 it would look like having the parent NAV element that houses a child UL element that houses the the child LI element. And the LI Element houses the child 'a' tag. Below i have created a comment for each relationship for the navigation with the link to go to main page. The parent elements should be indented on the same line vertically. The child elements should be indented two spaces from the parent vertically. However, it is not required that it is done this way specifically. As long as my code is consistent, it is good to go. I can go 4 spaces or 6, as long as its always the same in the code. Don't go 4 spaces on one element then 6 spaces on the next. Keep it consistent.
